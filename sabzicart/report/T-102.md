11.	Remove the empty dump folder with rmdir. Why is rmdir safer than rm -r here?

cd ~/sabzicart/shared-drive
rmdir dump

For the report: rmdir only removes an empty folder. If any file is still inside,
 it refuses with an error, so you can’t lose a file by mistake.
 rm -r deletes the folder and everything in it without asking.
